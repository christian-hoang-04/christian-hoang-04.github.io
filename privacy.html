Privacy and visitor logging

When visitor logging is enabled, each page sends its path from the visitor's browser to a Cloudflare Worker. The Worker records the visitor's IP address, the page path, and the time of the visit in a Cloudflare D1 database. This records browser visits where JavaScript runs; it is not a complete server access log.

Page paths are stored without query strings or fragments. This feature does not store cookies, browser user-agent strings, or referrers. The logs are available only through the site owner's authenticated Cloudflare account; there is no public log viewer.

A daily cleanup removes visit records after they pass 30 days, so deletion can occur up to 24 hours after that point. Visitor logging is used to understand traffic to this personal website.
